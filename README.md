# 🎮 Meu Jogo GRS 1

Bem-vindo ao repositório do **Meu Jogo GRS 1**, um projeto de jogo eletrônico focado em mecânicas de ação, perseguição e simulação de tráfego desenvolvido utilizando a engine **Unity** e linguagem **C#**.

## 📝 Sobre o Jogo
O projeto conta com mecânicas avançadas de jogabilidade, incluindo:
- **Sistema de Perseguição:** Inteligência artificial para viaturas policiais (`PoliciaCarro.cs`) com mecânicas de captura ativa (`Procurado.cs`).
- **Simulação de Tráfego:** Carros autônomos circulando pela cidade (`CarroAutonomo.cs` e `TrafegoCarro.cs`).
- **Interação com Veículos:** Mecânica para o jogador entrar e dirigir carros (`EntrarCarro.cs` e `CarroSimples.cs`).
- **Sistema de Economia:** Coleta de moedas, gerenciamento de banco e lojas integradas (`Dinheiro.cs`, `Banco.cs`, `Loja.cs`).

## 🛠️ Tecnologias Utilizadas
- **Engine:** Unity
- **Linguagem:** C# (.cs)
- **Componentes:** NavMesh (para movimentação e IA dos carros/polícia), Rigidbody (física) e programação orientada a objetos.

## 🚀 Como testar ou contribuir
1. Faça o clone deste repositório.
2. Abra a pasta raiz do projeto na sua versão da Unity.
3. Carregue a cena principal em `Assets/Scenes` e clique em Play!
